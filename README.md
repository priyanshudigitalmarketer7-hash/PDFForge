# PDFForge

A modern PDF creation and editing web application.

## Features

✔ Create PDF from text  
✔ Add images  
✔ Merge PDFs  
✔ Split PDFs  
✔ Password protection  
✔ Save projects  
✔ Responsive design

## Tech Stack

- React
- Tailwind CSS
- Node.js
- Express
- MongoDB
- pdf-lib

## Installation

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm start
```
